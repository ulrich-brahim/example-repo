# Shoe Warehouse Stock Manager

A Python inventory management program that reads shoe records from `inventory.txt`, represents each shoe as a `Shoe` object, and stores the objects in a list. A menu lets users manage and review warehouse stock.

## Features

- View all shoes in inventory.
- Add a new shoe to inventory.
- Restock the shoe with the lowest quantity.
- Search for a shoe by its product code (SKU).
- Calculate the total stock value for each shoe (`cost × quantity`).
- Identify the shoe with the highest quantity as the item on sale.
